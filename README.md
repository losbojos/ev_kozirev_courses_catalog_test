# Online Courses Catalog

Тестовое задание: каталог онлайн-курсов по макету Figma.

## Возможности

- Каталог курсов с адаптивной сеткой карточек (320–1920px, адаптивная вёрстка через clamp)
- Фильтрация по категориям
- Поиск по названию курса
- Постраничная подгрузка карточек
- Состояние «ничего не найдено»
- Данные загружаются из `data/courses.json`

## Стек

- БЭМ
- HTML, SCSS
- Vanilla JavaScript без библиотек

## Запуск

```bash
npm install        # установить зависимости (sass)
npm run build      # собрать css/main.css из scss/
npm run serve      # поднять локальный сервер
```

После `npm run serve` открыть адрес из вывода команды (обычно http://localhost:3000).

> Открывать `index.html` напрямую через `file://` нельзя — данные курсов
> загружаются через `fetch`, которому нужен HTTP-сервер.

Для разработки — пересборка стилей при изменении SCSS:

```bash
npm run dev
```

## Структура проекта

```
├── index.html              # разметка страницы + <template> карточки
├── code/
│   ├── Course.js           # модель курса (данные, форматирование)
│   └── main.js             # фильтры, поиск, рендер, подгрузка
├── data/
│   └── courses.json        # данные курсов
├── img/                    # изображения для курсов и декор
├── scss/
│   ├── main.scss           # точка входа
│   ├── _variables.scss     # переменные и вспомогательные функции
│   ├── _normalize.scss     # Нормализация CSS
│   ├── _reset.scss         # Сброс некоторых дефолтных свойств CSS
│   └── blocks/             # SCSS по БЭМ-блокам
└── css/                    # собранный CSS (генерируется, в git не входит)
```
